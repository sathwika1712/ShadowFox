# 💳 Bank Management System (Advanced GUI)

## 📌 Description
This project is an Advanced Bank Management System developed using Java Swing. It provides a graphical user interface for managing multiple bank accounts and performing various operations.

---

## 🚀 Features

- Create new bank accounts
- Deposit money
- Withdraw money
- Update account details
- Delete accounts
- View all accounts in a table
- Interactive GUI with colors and buttons

---

## 🖥️ Technologies Used

- Java
- Swing (GUI)
- AWT (Event Handling)

---

## 📊 Functionalities

### ➤ Add Account
Users can create a new account with name and initial balance.

### ➤ Deposit
Add money to selected account.

### ➤ Withdraw
Withdraw money with balance validation.

### ➤ Update
Modify account name and balance.

### ➤ Delete
Remove selected account from system.

### ➤ Table View
Displays all accounts in structured format.

---

## 🎯 Learning Outcomes

- GUI Development using Java Swing
- Event-driven programming
- CRUD operations
- Table handling using JTable
- User interaction design

---

## 📷 Output Preview

Graphical interface with:
- Input fields
- Buttons (Add, Deposit, Withdraw, Update, Delete)
- Table for account data

---

## 📌 Conclusion

This project demonstrates a complete GUI-based banking system with real-time interaction and multiple account management, making it suitable for learning intermediate to advanced Java concepts.
