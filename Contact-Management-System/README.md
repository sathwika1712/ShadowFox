Task 1 - Part 2: Contact Management System
📌 Description
This project is a simple console-based Contact Management System developed using Java. It allows users to manage contacts through a command-line interface.

⚙️ Features
Add new contact (Name, Phone, Email)
View all contacts
Update existing contact
Delete contact
🛠️ Technologies Used
Java
VS Code
▶️ How to Run
Open terminal
Compile the program: javac ContactManager.java
Run the program: java ContactManager
📂 Project Structure
Task1-Part2/ └── ContactManager.java

📖 Learning Outcomes
Understanding CRUD operations
Using ArrayList for dynamic data storage
Handling user input using Scanner
Implementing menu-driven programs
