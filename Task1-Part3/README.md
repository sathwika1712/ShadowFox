# Task 1 - Part 3: Student Information System

## 📌 Description

This task focuses on developing a Student Information System with a graphical user interface to manage student records efficiently. The system supports core operations such as adding, viewing, updating, and deleting student information.

Along with the required Java-based GUI implementation, an additional web-based version is developed using HTML, CSS, and JavaScript to provide an improved and user-friendly interface.

---

## ⚙️ Features

* Add student details (Name, Roll No, Course)
* View all student records
* Update existing student information
* Delete student records
* Interactive user interface for better usability
